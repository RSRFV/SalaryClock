# 安装包（Android / iOS）构建说明

> 网页版仍以仓库根目录为唯一事实来源；`mobile/` 是 Capacitor 壳工程，`android-native/` 是不依赖 Gradle 的原生 WebView 壳（已在本机构建出 APK）。

## 一、Android APK（已构建，可直接安装）

产物：`dist/SalaryClock-android-debug.apk`（约 70 KB，minSdk 21 / targetSdk 34，debug 签名）。

安装：把 APK 传到手机，允许「安装未知来源应用」后安装。debug 签名适合自用与内测，不能上架应用商店。

**为什么用 `android-native/`**：本机没有 Android SDK / JDK，且 HTTPS 出网被限制，Gradle + Maven 拉不动依赖；于是用 HTTP 下载 JDK 17 + build-tools 34 + platform 34，直接走 `aapt2 → javac → d8 → zipalign → apksigner` 手工打包。WebView 里 ES Module 会被 `file://` 的 CORS 拦住，所以构建时把 `calc.js` + `app.js` 合并成普通脚本 `app.bundle.js`。

本地重建（需 PowerShell + 已放置的 `.tools` 工具链）：

```powershell
cd android-native
.\build.ps1
```

仓库里同时保留了 GitHub Actions 的 Capacitor 构建（`Build Android APK`），有网的环境下也可用。

## 二、iOS（重要限制）

**iOS 安装包必须由 Apple 签名，Windows 上无法生成可安装的 .ipa。** 仓库提供了 `Build iOS (unsigned)` 工作流，能在 macOS runner 上产出**未签名** `dist/SalaryClock-ios-unsigned.ipa`，但它不能直接安装，需要再用你的 Apple ID 签名：

| 方式 | 需要什么 | 结果 |
| --- | --- | --- |
| **PWA 添加到主屏**（最快） | 一个 HTTPS 地址（GitHub Pages / Vercel / Netlify 均可） | 类 App 全屏体验，离线可用，立刻能用 |
| Sideloadly / AltStore 自签 | Windows/Mac + 免费 Apple ID | 装到自己的 iPhone，**7 天需重签** |
| TestFlight / App Store | Apple Developer Program（$99/年）+ 证书 | 可长期安装、可分发给他人 |

如果需要我按其中一种方式继续（比如配 GitHub Pages 或 EAS 构建），告诉我你的 Apple 开发者账号情况即可。

## 三、本地构建（可选）

需要：Node 20+、JDK 17、Android SDK（platform 34 + build-tools 34）。

```bash
cd mobile
npm install
node scripts/build-web.mjs
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# 产物：mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

iOS 需要 macOS + Xcode 15+：

```bash
cd mobile
npm install && node scripts/build-web.mjs
npx cap add ios
npx cap sync ios
npx cap open ios   # 在 Xcode 里配置签名后 Run / Archive
```

## 四、发布签名

- Android 上架需自建 keystore 并在 `mobile/android/app/build.gradle` 配置 `signingConfigs`；keystore 不要提交到仓库。
- iOS 上架需在 Xcode 配置 Team / Provisioning Profile，或使用 EAS / Fastlane 云构建。
