# 后端与同步（SalaryClock Server）

零第三方依赖的 Node 服务：注册/登录 + 单用户快照同步 + 托管前端静态文件。

## 启动

```powershell
node server/index.mjs
# 可选：$env:PORT=9000; $env:HOST=0.0.0.0; node server/index.mjs
```

默认 `http://127.0.0.1:8788`，打开即为「前端 + API 同源」模式，设置里服务器地址留空即可。

## 数据与安全

| 项 | 说明 |
| --- | --- |
| 存储 | `server/data/users.json`（已 gitignore），包含用户、scrypt 哈希、快照 |
| 密钥 | `server/data/secret.key`（首次启动生成，用于签发 token；**务必备份**，丢失后所有登录失效） |
| 密码 | `scrypt` 加盐哈希，不存明文 |
| Token | HMAC-SHA256，30 天有效期，`Authorization: Bearer <token>` |
| 限流 | 同一 IP 每分钟最多 20 次注册/登录尝试 |
| 体积 | 单次请求上限 4 MB |

> 本地调试允许 HTTP；**公网部署必须加 HTTPS**（Nginx/Caddy 反代），否则密码与 token 明文传输。

## 同步模型

- 客户端把 `{settings, days, months}` 作为**整包快照**上传，服务端只保留最新一份。
- 登录时拉取云端 → 与本机**合并**（按日期取并集，冲突时本机优先）→ 再推送合并结果。
- 登录后每次保存延迟 2.5 秒自动推送；设置里可关闭自动同步。
- 没有做多端并发冲突检测，适合单人多设备；如以后要多端同时编辑，再加版本号与字段级合并。

## 部署建议

1. 任意 Node 18+ 主机，`node server/index.mjs` 即可；建议 systemd / pm2 守护。
2. 用 Caddy 自动 HTTPS：

```caddyfile
salary.example.com {
  reverse_proxy 127.0.0.1:8788
}
```

3. 备份 `server/data/`（users.json + secret.key）。
4. Docker 示例（可选）：

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY . .
EXPOSE 8788
CMD ["node", "server/index.mjs"]
```

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| POST | `/api/auth/register` | `{username, password}`，返回 `{token, user}` |
| POST | `/api/auth/login` | 同上 |
| GET | `/api/sync` | 需 Bearer token，返回 `{data, updatedAt}` |
| PUT | `/api/sync` | 需 Bearer token，`{data, updatedAt}` |
| GET | `/api/holidays?year=2026` | 节假日日历（代理上游 + 7 天缓存） |

## 节假日日历

客户端优先读取**本机日历**里的节假日事件（Android 原生桥，`READ_CALENDAR` 权限），打开 App 自动同步；读不到时回退到服务端接口。

服务端默认请求 `https://timor.tech/api/holiday/year/{year}`，可用环境变量覆盖：

```powershell
$env:HOLIDAY_API = "https://your-api/holiday/{year}"
node server/index.mjs
```

- 成功结果缓存到 `server/data/holidays-<year>.json`（7 天 TTL）
- 上游不可达时：有缓存用缓存，无缓存返回 `502 {error}`
- 本地无外网时，可用 `node tests/mock-holiday.mjs` 起一个模拟上游做联调

## 前端配置

设置 → 账户与同步 → 服务器地址：

- 用 `node server/index.mjs` 打开 8788：留空（同源）
- 静态预览 8787：填 `http://127.0.0.1:8788`
- Android APK：填你部署的 HTTPS 地址（如 `https://salary.example.com`）
